# Трассировка ТЗ → тесты

Все Mxx находятся в `tests/acceptance.test.mjs`.

| ID | Требование |
|---|---|
| M01 | Комплект использует количество материалов из настроек администратора |
| M02 | Недопущенной команде комплект не готовится |
| M03 | Дополнительные бланки имеют уникальные ID и QR, нужную принадлежность |
| M04 | В бонусах разрешены +N и ×N, задача фиксируется при выпуске |
| M05 | В домино и крестиках-ноликах модификаторы запрещены |
| M06 | Наблюдатель/проверяющий/организатор не выпускают новые бланки |
| M07 | Подделка/неизвестный QR не проходят проверку |
| M08 | Повтор выпуска не создаёт новые бланки; ключ нельзя переиспользовать с другим телом |
| M09 | Наблюдатель печатает часть и полный доступный комплект без изменения QR |
| M10 | Администратор получает единый PDF заданий и бланков без эталонов в manifest |
| M11 | Материалы чужой команды/игры не включаются в выбранный комплект |
| M12 | Печать не доступна гостю, организатору и проверяющему |
| M13 | Параллельный выпуск не создаёт совпадающие ID/QR |
| M14 | Домино учитывает режим общих карточек |
| M15 | Публикация события выпуска соответствует созданным бланкам |
| M16 | Пустой запрос печати и недопустимое количество отклоняются |
| M17 | Несколько глобальных ролей суммируются |
| M18 | Администратор собирает материалы разных команд игры в один PDF |
| M19 | В PDF не допускается условие задачи из другой игры |

| M20 | Каждый бланк до печати связан с задачей этой игры |
| M21 | Новый тип игры использует конфигурацию шаблона и возможностей |
| M22 | Шаблоны одной системы могут различаться; созданный PDF-запрос сохраняет выбор |
| M23 | Эталон не раскрывается через API бланков |

Утрата бланка не имеет команды автоматической замены; доступно только явное
решение о печати/выпуске. Ручное качество PDF, криптографическая стойкость QR и
отсутствие эталонов внутри отрисованного PDF требуют дополнительных тестов после
выбора технологий, см. SERVICE.md. Эти проверки не объявлены выполненными.
| M24 | Исправленный эталон получает новый ID задачи, не подменяя выпущенные бланки или материалы игры |
