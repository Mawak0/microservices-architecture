| R09 | В домино апелляций нет |
| R10 | После срока подачи апелляция запрещена |
| R11 | До исходного вердикта апелляция запрещена |
| R12 | Квота общая для всех команд игры |
| R13 | Конкурентные обращения не превышают остаток квоты |
| R14 | Повторное обжалование задания запрещено |

| R28 | Роли и внутренние операции защищены |
| R29 | Возврат назначения не теряет дело |
| R30 | События апелляции позволяют внешней таблице показать/снять ожидание |
| R31 | Нулевой лимит и ограничение прав на изменение квоты |
| R32 | Повтор сохранения вердикта не меняет revision повторно |

неразборчивый текст вне покрытия этого сервиса/текущих согласованных правил.
